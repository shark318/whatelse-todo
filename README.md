# 还有什么

> 一个只问你「还有什么要做」的本地待办清单。

Android 待办清单 App：**纯本地存储、不联网、不需要账号**。用 uni-app（Vue 3）开发，通过 HBuilderX 云打包成 APK，直接装到自己的小米手机上。

---

## 它是什么

- **只做一件事**：记下要做的，做完打勾。没有项目、没有团队协作、没有会员订阅。
- **数据只在自己手机里**：不需要注册、不需要联网，飞行模式下也能正常用。
- **为小米 HyperOS 调优**：打包步骤、权限授予、后台保活设置都按 HyperOS 的菜单路径写好了。

## 技术栈

| 层面 | 选择 | 为什么 |
| --- | --- | --- |
| 框架 | uni-app（Vue 3 + `<script setup>`） | 一套 Vue 语法搞定，免装 Android SDK，HBuilderX 可视化云打包 |
| 本地存储 | `uni.setStorageSync` + Repository 封装 | 待办数据量小，零依赖最稳；日后数据量大了可平滑换成 SQLite |
| 提醒 | `uni.createPushMessage`（零原生插件） | 官方 API，云打包最省事；代价是 App 被系统清理后不提醒 |
| 打包 | HBuilderX 云打包 → APK | 免费，免装 Android Studio，公共测试证书即可自己装 |
| 目标机型 | 小米 / 红米 HyperOS（Android 14+） | 向下兼容至 Android 8.0 |
